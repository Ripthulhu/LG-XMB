# 0.1.19 — Wave post-process antialiasing

Add an output-resolution FXAA pass after the supersampled waves are resolved
and composited with the background. Text and icons are still browser layers;
they are not included in the filter. The canvas stays at up to 1920 by 1080.

Settings → Waves adds **Post-process antialiasing** (Off, FXAA, Wave FXAA) and
**Smoothing strength** (Gentle, Normal, Strong). FXAA / Normal is the default.
Wave FXAA is an experimental variant using accumulated wave opacity, rather
than display luminance, to detect edges. Both filter the complete RGB image;
no mismatched alpha-only blur, temporal history or new gamma transform is used.
The preceding Antialiasing setting is renamed **Supersampling** without changing
its stored value. Mesh detail, edge softness and the other wave controls remain.

The optional pass uses one output-size RGBA8 texture (about 7.9 MiB at 1080p).
Off releases its texture. Shader or surface refusal disables only the optional
pass, reports the reason and retains the PS3 renderer and requested preference.
A refused size is not retried every frame. Context restoration allows a retry.

Keep the previous wave geometry, theme colours, timing, 1080p output cap and
helper behavior. The controller changes only its version-specific manifest pin.
Install over 0.1.18; do not remove settings or reinstall the helper separately.

This remains an experimental C5 build. FXAA reduces pixel stair-steps; it does
not reconstruct an irregular geometric contour or guarantee PS3-exact rendering.
Compare Off and FXAA at fixed sampling/detail, then check motion and navigation
on the TV. Higher presets and native TV GPU performance are not established by
software-rendered browser tests. Existing native model-gating, concurrent-setup
Busy reporting and worker-output limitations are unchanged. AI-assisted change.
