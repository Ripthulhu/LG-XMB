# 0.1.16 — PS3-style wave test build

The default background now uses a folded spline surface adapted from
linkev/PlayStation-3-XMB, rather than five independent glowing lines.
Existing themes tint the surface; animation, speed and brightness controls
retain their behavior. This is a reconstruction, not an exact PS3 renderer.
Particles and day/night color presets are not part of this pass.

The renderer uses WebGL 1 and regular RGBA8 storage. It retains a 30 fps cap,
pauses when Home is hidden, and holds a still when animation is disabled.
Failures fall back to the original WebGL waves, then Canvas2D.
No new runtime libraries or external requests are added.

This build includes the previously tested helper-directory repair and
Allow/on background switches. Saved choices and the installed app ID are
unchanged. Helper behavior is unchanged apart from the new version's manifest
pin. Install the IPK over the working version; do not delete helper settings.

This remains a C5 test build. GPU performance, switching away and returning to
Home, and wave appearance must be checked on the TV. The existing helper
model-gating and logging limitations are unchanged. AI-assisted changes.
