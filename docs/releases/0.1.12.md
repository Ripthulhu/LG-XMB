C5 test build. Install the `.ipk` asset with webOS Dev Manager and open **Home**.
The helper is included; no separate SSH installation or helper download is needed.

## Changes

- Native HDMI names follow the labels configured on the TV.
- Previous item icons move above the horizontal category bar when scrolling.
- The app prepares its bundled helper through Homebrew Channel on first launch.
  **Settings → Input previews** shows helper status and a retry action.
- Runtime paths use `lg-xmb`. Valid legacy settings and restoration values are
  migrated; new background controls default to **Allow**.
- Startup uses an app-owned symlink. The installed app ID remains
  `org.local.openxmb.c5` for in-place upgrades and existing Home assignments.
- Includes the webOS 22 preview-layout fallback and compatibility groundwork.

## Requirements and limitations

Privileged features require an already rooted Homebrew Channel environment and
Python 3.7 or newer. Setup does not root the TV or assign the Home button.
Cached pictures become available only after an eligible HDMI input is viewed.

**Use this prerelease on the C5 test target only.** webOS 22–26 is a launcher
compatibility target, not validated support for its privileged integrations.
The current automatic bootstrap does not enforce a model/SDK restriction, and
startup diagnostics remain incomplete. These are known gaps, not fixed in this
release.

Automated unit, browser and package checks passed. Native input labels were
confirmed on the maintainer's TV in the preceding candidate. Clean setup,
capture, Home remapping, reboot, upgrade and recovery in this build still need
on-TV validation. AI-assisted code requires meaningful maintainer review before
broad distribution or Homebrew submission.

Before uninstalling, restore **LG Home** and set managed background controls to
**Allow**. Removing the app prevents future boot starts but does not undo TV
settings. Follow `docs/INSTALLATION.md` in the matching source for recovery.
