# LG-XMB 0.1.39

- Keep the category bar and item lists aligned during fast scrolling, direction changes and dropped frames.
- Smooth out category, list and highlight fades. Fades finish while the menu is still moving, and vertical scrolling moves more slowly. Simple animations remain available under Appearance → Advanced.
- Match the category icon sizes and focus zoom more closely to the PS3. Refine the TV icon's outline and the Network globe.
- Route Home through LG's native input services to handle physical IR remotes that the old listener missed. This works alongside stock LG Home. Physical IR and Logitech Harmony Home presses were tested on the C5; Wi-Fi remote apps such as ColorControl are not covered.

The scrolling changes were tested on the C5 and in desktop Chromium 79. Other
TV models still need confirmation for the new Home-button routing. Overlapping
fades can cost frames on slower TVs; Simple animations reduce that work.

Install or update through Homebrew Channel using the [installation guide](../INSTALLATION.md).
Running alongside stock LG Home is the recommended setup. Home replacement
has only been tested on the LG C5 with webOS 25; existing replacements also
need the separate [payload update](../HOME-TAKEOVER.md#updating-the-payload).
