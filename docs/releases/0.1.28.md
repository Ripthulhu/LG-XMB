# 0.1.28

- Simplify category changes to one incoming list and two container animations.
  Remove the cloned outgoing column and per-icon category animations.
- Preserve the common 180 ms timing, above-bar labels, rapid reversals, pointer
  jumps and immediate selection. Animation failure falls back to a static menu.
- Reuse detached menu rows and refresh their labels when a category is opened.
  Newly discovered apps still receive rows; inactive rows cannot launch items.
- Remove permanent per-row/category layer hints. Only the two moving containers
  request promotion, and release it when the transition ends.

Built on the supplied 0.1.27 MSAA source confirmed working by the maintainer.
Wave/MSAA, particle, colour and native-helper implementations are unchanged;
the controller's app manifest pin changes with the version. Music remains
user-supplied at `/media/internal/lg-xmb/background.mp3`.

Menu appearance and performance need an on-TV comparison before release.
