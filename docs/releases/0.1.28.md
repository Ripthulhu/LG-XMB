# LG-XMB 0.1.28

This integrates the tested feature branches and the MSAA work into one build.

- Replace the long, overlapping category-list swipe with a short directional
  reveal. Only the live column and horizontal bar animate; both share the same
  180 ms timing. Category rows and their SVG icons are reused on return.
- Remove transition-time DOM cloning, per-button layout/style reads, per-icon
  colour animation and permanent per-row layer hints. Rapid reversals retain
  the current bar position and do not repeatedly fade the column to invisible.
- Include the cropped supersampled wave renderer and configurable Off/2x/4x
  MSAA, with capability checks and reported fallbacks. Existing wave settings,
  monthly Day/Night gradients, RGB controls and depth-style particles remain.
- Retain automatic helper ownership recovery and concurrent-setup handling,
  native input labels, cached/live previews, remote mapping and Allow/on switches.
- Music remains optional and user-supplied at
  `/media/internal/lg-xmb/background.mp3`. No recording is included.

Install over the current app using webOS Dev Manager; do not delete helper state
or settings. The installed app ID remains `org.local.openxmb.c5` for upgrades.
The maintainer reports 0.1.27 works on the TV. The revised animation still needs
on-TV appearance and performance confirmation; desktop checks are not a TV
frame-rate benchmark. Broader webOS 22–26 support remains a development target.
