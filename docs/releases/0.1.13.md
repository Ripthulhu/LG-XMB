C5 test build fixing the 0.1.12 helper startup failure.

## Fixed

- The IPK now gives the app's directories mode 0755 and root ownership. The
  previous packager emitted `helper/` as 0777, which the bootstrap correctly
  refused before it could start the helper. Runtime ownership and path checks
  remain in place; shared TV ancestor permissions are not changed.
- Setup records early failures in `/var/lib/webosbrew/lg-xmb-startup.log`,
  including directory owner/mode and the failing code location. The root-only
  log is limited to 16 KiB. Raw native responses and settings are not logged.
- Package verification checks directories and ownership as well as file bytes.

## Install

Install the `.ipk` over 0.1.12 with webOS Dev Manager and open **Home**.
No separate helper installation or manual chmod is required by this build.
Keep existing `/var/lib/lg-xmb` settings. **Settings → Input previews** shows setup
status; Home assignment remains a separate choice under **Remote buttons**.

## Limitations

This is a C5 prerelease, not a Homebrew submission. It still requires an already
rooted Homebrew Channel environment and Python 3.7 or newer on the TV. The
bootstrap still has no model/SDK gate; do not use it on unverified TVs.
The package permission bug is reproduced in tests; installation, cached capture,
Home mapping and reboot still require on-device retesting. The setup log is not
a full worker output log. Restore LG Home and background choices before removing
the app. No TV deployment was performed by CI. AI-assisted implementation.
