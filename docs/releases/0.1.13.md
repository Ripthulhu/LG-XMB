C5 test build. Install the IPK over 0.1.12 and open **Home**.

## Fixes

- Keep text beside the item icons above the horizontal category bar. Long names
  retain the normal ellipsis and can be selected by clicking their text.
- Set the app and helper directory modes explicitly during packaging. The
  previous IPK contained a world-writable helper directory that setup rejected.
- Verify the pinned bundle before repairing root-owned installed file modes.
  Foreign owners, links, changed bytes and path replacements remain refused.
- Write the startup log before bundle validation, including the failing stage,
  error code and line locations. See `/var/lib/webosbrew/lg-xmb-startup.log`.

The helper remains app-owned and automatic. No manual helper copy, recursive
permission change or configuration deletion is needed. Saved settings and the
installed app ID are unchanged. Check **Settings → Input previews** after opening
Home; cached images require an eligible HDMI input to have been viewed.

## Limitations

This is a prerelease for the C5 test target, not Homebrew approval or verified
support across webOS 22–26. The existing bootstrap still has no model/SDK gate.
Native clean setup, capture, Home mapping, reboot and recovery need on-TV retests.
The startup log is capped at 8 KiB and records one attempt; raw worker output is
not retained. No log can be created without root or a safe writable log directory.

Before uninstalling, restore LG Home and set managed background controls to
Allow. Follow the recovery steps in the matching source's installation guide.
AI-assisted changes require maintainer review before broad distribution.
