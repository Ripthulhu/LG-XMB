# 0.1.18 — Wave edge quality controls

Keep 1080p output and add three controls under Settings → Waves:

- Antialiasing: Off (1×), 1.25×, 1.5×, or 2× internal supersampling.
- Mesh detail: Standard (128 × 48), High (256 × 96), or Fine (384 × 128).
- Edge softness: Sharp, Subtle, or Soft.

New defaults are 1.5×, High and Subtle. Existing animation, theme, speed,
brightness, preview and remote preferences are preserved. The controls apply
without restarting and remain saved across launches. The menu reports internal
resolution and any reduced sample factor forced by a GPU limit/allocation failure.

Supersampling addresses pixel stair-steps; denser geometry reduces polygonal
silhouettes. Keep WebGL 1, linear filtering, premultiplied-alpha compositing,
the 30 fps cap, hidden suspension, frozen frames and the existing fallbacks.
The composite uses high-precision texture coordinates where supported.

Higher settings cost GPU memory/fill rate and denser meshes cost CPU time.
No TV performance claim is made for the new defaults or the highest settings.
Set Off / Standard / Soft to match the previous resolution, mesh and filter.

The working helper, Allow/on switches, labels and remote features are retained.
Only the controller's existing manifest pin changes for the version bump.
Existing helper model-gating, concurrent setup and worker-output limitations
remain. Install over the current app without deleting configuration.

AI-assisted changes; on-TV appearance and performance require maintainer review.
