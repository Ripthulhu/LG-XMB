# LG-XMB 0.1.36

- Reduce scrolling and category-transition overhead without changing animation timing or particle motion.
- Add a saved Simple/PS3 choice under Appearance → Advanced → Menu animations.
- Refine icon alignment, selection glow, menu dividers and PS3 clock sizing.
- Add Homebrew Channel installation instructions and an animated README preview.

Scrolling with the full background effects can still drop below 60 fps.

Install or update through Homebrew Channel using the [installation guide](../INSTALLATION.md).
Running alongside stock LG Home with remote-button settings is the recommended setup.
Home replacement has only been tested on the LG C5 with webOS 25; existing replacements
also need the separate [payload update](../HOME-TAKEOVER.md#updating-the-payload).
