# 0.1.17 — 1080p wave test build

Request 1920 by 1080 for both the wave canvas and its intermediate surface.
Remove the TV-only 720p default and disable automatic resolution reduction in
the app. Smaller viewports and GPU capability limits remain respected.

Keep the existing spline shape, softening filter, 30 fps target, themes, speed,
brightness, animation-Off frame, suspension and renderer fallbacks. The helper
repair and Allow/on switches are unchanged; the controller manifest pin changes
only to match this version. Existing settings are not reset.

The intermediate RGBA8 texture uses about 7.9 MiB instead of 3.5 MiB. Actual TV
performance at 1080p requires testing; the 30 fps target is not a benchmark.
Native helper compatibility and boot logging limitations are unchanged.
