# 0.1.17 — Full-HD PS3 waves

Render both the wave canvas and its off-screen spline surface at up to
1920 by 1080. Previously the TV requested a 720p canvas and the spline surface
had its own 720p cap. Disable automatic resolution drops caused by scheduling
gaps so the requested full-HD detail is retained. Smaller preview windows and
hard GPU limits are still respected.

Keep the existing wave shape, mesh, lighting, softening pass, theme tint, speed,
brightness and 30 fps cap. Hidden suspension, frozen animation and renderer
fallbacks are unchanged. Full HD has 2.25 times the pixels of 720p; actual TV
performance needs retesting.

Retain the working helper-directory repair, Allow/on switches, input labels
and remote settings. The controller changes only its manifest pin for this
version. Install over the current app without deleting configuration.

This remains an experimental C5 build. Existing helper model-gating,
concurrent-setup Busy reporting and worker-output limitations are unchanged.
AI-assisted changes.
