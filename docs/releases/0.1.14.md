C5 test build retaining the text on items above the horizontal category bar.

## Changes

- Previous items keep their labels beside their icons while scrolling above the
  category bar. The existing fade, spacing and selected-item position are unchanged.
- Upper labels remain clickable. Long input and app names use the existing ellipsis.
- Includes the 0.1.13 helper packaging and early-logging fixes. App-owned IPK
  directories are root-owned 0755; runtime ownership and integrity checks remain
  in place. No second installer or runtime permission-repair mechanism is added.

## Install

Install the `.ipk` over the existing app with webOS Dev Manager and open **Home**.
Keep `/var/lib/lg-xmb` settings; do not delete them or apply a recursive chmod.
The app prepares its bundled helper automatically. **Settings → Input previews**
shows setup status. Home assignment remains a separate choice in **Remote buttons**.

Setup diagnostics are in `/var/lib/webosbrew/lg-xmb-startup.log`, including
failures before bundle loading. Capture status, after the worker initializes,
is in `/tmp/lg-xmb-thumbnails/status.json`. This build fixes the packaged 0777
helper directory seen in 0.1.12; it does not claim to resolve every native error.

## Validation and limitations

The upper-label tests cover visibility, pointer activation, long-name truncation
and reverse scrolling at 720p and 1080p. Browser tests simulate the TV; they do not
establish native behavior. Use this prerelease on the C5 test target only. The
helper still requires rooted Homebrew Channel and Python 3.7 or newer and lacks
a model/SDK gate. On-TV setup, capture, mapping, reboot and removal need retesting.
The setup log is not a full worker-output log. Restore LG Home and managed
background choices before uninstalling. AI-assisted changes require maintainer review.
