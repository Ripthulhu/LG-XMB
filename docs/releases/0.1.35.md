# LG-XMB 0.1.35

- Remove obsolete UI styles, unused renderer paths and retired build options.
- Shorten the documentation, consolidate older release notes and remove the outdated menu-animation guide.
- Recommend running as a normal webOS app with remote-button settings. Home replacement has only been tested on a C5 with webOS 25; other TVs need manual investigation before attempting it.

Install the IPK using the [installation guide](../INSTALLATION.md).
Existing LG Home replacements also need the separate [payload update](../HOME-TAKEOVER.md#updating-the-payload).
