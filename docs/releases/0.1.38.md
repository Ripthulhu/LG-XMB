# LG-XMB 0.1.38

- Move inputs into other categories. For example, put an HDMI-connected DVD player under Video. Long-press the item and choose Categories.
- Choose an icon for any app or input from its long-press menu. The list is alphabetical, with Default icon at the top. It includes eight new icons: Disc, Media search, Headset, Screen, Handheld, PC, Media streamer and Game console.
- Add a switch under Settings → Input previews to pause the background during live previews for better performance. Pausing is off by default; Cached remains the default preview mode.
- Fix Back-button access to recent apps when running alongside LG Home on TVs that deny the app's direct request.

The menus and renderer were checked on the C5 and in Chromium 79. The Back-button
permission fix still needs confirmation on the affected older TVs.

Install or update through Homebrew Channel using the [installation guide](../INSTALLATION.md).
Running alongside stock LG Home is the recommended setup. Home replacement
has only been tested on the LG C5 with webOS 25; existing replacements also
need the separate [payload update](../HOME-TAKEOVER.md#updating-the-payload).
