# LG-XMB 0.1.30

- Reduce spline CPU work by evaluating only sampled descriptor-table rows and
  reusing row/column calculations. Regression tests verify byte-identical
  vertices, normals, heights and kernel values against the previous evaluator.
- Avoid redundant category-bar and row-state updates during navigation, reuse
  matching detail icons and leave already-focused item lists alone. Selection
  and activation remain immediate; CSS and transition timings are unchanged.
- Keep animation deadlines stable after late callbacks without catch-up draws.
  The WebGL target remains 30 fps and the Canvas2D fallback remains 20 fps.
- Preserve resolution, mesh density, supersampling, antialiasing, shaders and
  particle appearance/count. Native input labels, previews and remote mapping
  are unchanged. The helper changes only its version-specific manifest pin.

Install over the existing app without clearing settings or helper state.
The installed app ID remains `org.local.openxmb.c5` for upgrades.

Local CPU benchmarks measured about 25% less spline-update time at the default
mesh. This is not a TV frame-rate measurement. On-TV installation, upgrade,
removal/recovery and animation performance still need validation for this build;
GPU-bound stutter may remain. Other TV/webOS combinations remain untested.
See `docs/performance/navigation.md` for the reproducible benchmark and TV checks.

AI-assisted implementation and validation. This remains a development prerelease.
