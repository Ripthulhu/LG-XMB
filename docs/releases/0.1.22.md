# 0.1.22 — Particles and user-supplied music

- Add the Mart/linkev point-sprite particle layer, adapted to WebGL 1 with saved
  On/Off and Low/Normal/High density controls. Share wave speed, brightness,
  frozen animation and hidden-app suspension. Preserve the existing AA pipeline.
- Keep music off by default, with loop and volume controls. No recording is
  included or downloaded. Copy an MP3 to `/var/lib/lg-xmb/music/background.mp3`.
  Optional setup recreates the app-relative link without modifying the track.
- Exclude local preview recordings from both Git and package staging.

Based on the helper-setup race fix in 0.1.20. No change to capture, remote mapping,
background restrictions or the saved user choices for those features.
The 0.1.21 install failure has not been reproduced; removing its recording is
not a demonstrated fix for that failure. Keep this a test build until TV retest.
