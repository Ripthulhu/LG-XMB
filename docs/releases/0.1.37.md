# LG-XMB 0.1.37

- Route the Home button directly to LG-XMB when running alongside stock LG Home. The saved choice returns after reboot without opening LG-XMB at boot or changing Power On Screen.
- Support Python 2.7 and Python 3 for Home-button routing and the preview helper. Remote device discovery follows the routing used by Magic Mapper on older and newer webOS versions.
- Add 12-hour and 24-hour time settings. Dates use the short PS3 style: day first (`20/9`) or month first (`9/20`), with no year or leading zeroes. Existing preferences migrate automatically.

Home-button routing was tested on the C5 with physical Home, arrow and wheel
input, and after reboot with Recent Input selected. Older TV models, including
the C4, still need hardware testing. Python compatibility alone does not confirm
remote or capture support on a particular TV.

Install or update through Homebrew Channel using the [installation guide](../INSTALLATION.md).
Running alongside stock LG Home is the recommended setup. Home replacement
has only been tested on the LG C5 with webOS 25; existing replacements also
need the separate [payload update](../HOME-TAKEOVER.md#updating-the-payload).
